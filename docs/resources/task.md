# Resource nexus_task
Use this resource to manage Nexus scheduled tasks. Tasks can be configured to run on various schedules and perform maintenance operations like blobstore compaction, repository cleanup, and more.

**Note:** When creating a task with `schedule = "cron"`, Nexus may return `schedule = "advanced"` in API responses. The provider automatically normalizes this to prevent perpetual drift in Terraform plans.

## Example Usage
```terraform
resource "nexus_task" "compact_blobstore" {
  name                   = "Compact All Blobstores Daily"
  type                   = "blobstore.compact"
  enabled                = true
  notification_condition = "FAILURE"

  frequency {
    schedule        = "cron"
    cron_expression = "0 15 4 * * ?"
  }

  properties = {
    blobstoreName  = "(All Blob Stores)"
    blobsOlderThan = "3"
  }
}
```

## Example: Manual Task
```terraform
resource "nexus_task" "manual_cleanup" {
  name                   = "Manual Cleanup Task"
  type                   = "repository.cleanup"
  enabled                = true
  notification_condition = "FAILURE"

  frequency {
    schedule = "manual"
  }

  properties = {
    repositoryName = "my-repo"
  }
}
```

## Import
Import is supported using the following syntax:
```shell
# import using the task ID
terraform import nexus_task.compact_blobstore <task-id>
```

## Task Types and Properties

Different task types require different properties. Here are some common task types:

- **blobstore.compact**: Compact blobstore soft-deleted blobs
  - `blobstoreName`: Name of blobstore or "(All Blob Stores)"
  - `blobsOlderThan`: Days (e.g., "3")

- **repository.docker.gc**: Docker cleanup unused manifests and layers
  - `repositoryName`: Name of Docker repository

- **repository.cleanup**: Apply cleanup policies
  - `repositoryName`: Name of repository

Consult Nexus documentation for the complete list of task types and their required properties.
